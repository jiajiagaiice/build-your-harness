# Executing Plans

- Inspect the existing tree before creating or moving files.
- Make cohesive changes that match the current plan step.
- Avoid speculative abstractions until a workflow, schema, or UI requirement needs them.
- After each meaningful change, check status and keep generated artifacts consistent.
