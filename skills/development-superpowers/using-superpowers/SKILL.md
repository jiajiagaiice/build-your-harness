# Using Superpowers

1. Identify the current phase: discovery, planning, implementation, testing, review, or final verification.
2. Load only the phase-specific `SKILL.md` files required for the task.
3. Keep the active harness visible by updating the plan before moving phases.
4. Prefer small, validated steps over broad unverified changes.
