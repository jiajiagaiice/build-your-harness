# Requesting Code Review

Review the diff for:

- Correctness against the stated user goal.
- Schema compatibility between UI, exporter, docs, and examples.
- Clear names and minimal coupling.
- Missing tests, missing docs, or hidden environment assumptions.
- Generated files or dependencies that should not be committed.
