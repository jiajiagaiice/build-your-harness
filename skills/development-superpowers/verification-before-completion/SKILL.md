# Verification Before Completion

- Run the agreed programmatic checks and capture exact commands.
- Inspect `git status` to ensure the final patch is intentional.
- Summarize changed files by user-visible outcome.
- Report warnings only for environment limitations; report failures as issues to fix before completion when possible.
