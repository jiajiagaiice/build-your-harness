# Development Superpowers Harness

This harness is the project-local development workflow for Build Your Harness. It is inspired by composable skill systems such as Superpowers, but the instructions here are original and tailored to this repository.

## Flow

```text
using-superpowers → brainstorming → writing-plans → executing-plans → test-driven-development → requesting-code-review → verification-before-completion
```

Use the workflow as a default development harness. Load individual skill files from `skills/development-superpowers/` only when their phase is relevant.
